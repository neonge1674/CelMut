This is a library for operating on cells

===DOCUMENTATION===

Cell:
A class that hase a head and a tail

Tower:
A class that hold multiple cells together

All the functions bellow are recursive

add(a, b):
Performs cell addition

actSub(a, b):
Performs active cell subtraction

pasSub(a, b):
Performs passive cell subtraction

mult(a, b):
Performs cell multiplication

actDiv(a, b):
Performs active cell division

pasSub(a, b):
Performs passive cell division

exp(a, b):
Performs cell exponentiation

root(a, b):
Performs cell root

log(a, b):
Performs cell logarithm
